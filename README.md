# Secure Wireless Control System on FPGA and Embedded Platforms

## 项目概览

本项目实现了一个基于 PC、ESP32、FPGA 和 STM32 的端到端安全无线控制系统，以四轮小车作为真实执行载体，完成无线指令传输、FPGA侧数据处理、嵌入式控制以及状态回传。

作品参加第十届全国大学生集成电路创新创业大赛 Robei 企业命题，获华中分赛区二等奖。

系统整体链路：

```
PC控制端
   ↓ Wi-Fi / UDP
ESP32通信模块
   ↓ UART
FPGA处理模块
   ↓ UART
STM32控制模块
   ↓
电机执行
```

返回方向由 STM32 生成设备状态，经 FPGA 处理后返回 PC，实现控制闭环。

## 系统设计

项目将网络通信、FPGA安全事务处理和物理执行进行分层设计：

- PC：生成控制请求、接收设备状态；
- ESP32：负责 Wi-Fi 网络接入和 UART 数据桥接；
- FPGA：完成协议处理、状态校验、安全事务处理和控制链路集成；
- STM32：完成控制指令解析、电机驱动和状态生成。

## 主要工程工作

- 完成系统总体架构设计、模块划分和设备间接口定义；
- 完成 PC、ESP32、FPGA、STM32 四节点通信链路集成；
- 完成 ESP32 Wi-Fi/UDP 通信与 UART 桥接调试；
- 完成 STM32 控制逻辑、PWM/GPIO 电机控制、状态回传和失联停车机制；
- 基于公开 AES/SM4 参考核心完成 FPGA 接口适配、事务控制和系统集成；
- 完成软件、RTL、综合实现和真实硬件环境下的分层测试与问题定位；
- 建立代码版本、固件产物、bitstream 和测试日志的可追溯记录。

## 工程特点

### 多节点软硬件协同

系统涉及网络通信、FPGA逻辑、嵌入式控制和真实执行设备，需要在多个软硬件模块之间进行接口设计和联合调试。

### 分层验证流程

针对复杂系统调试，采用模块级验证 → 链路级验证 → 整机测试的方式定位问题，分别验证通信、协议处理、控制执行和异常保护功能。

### 安全与可靠性设计

系统包含通信校验、状态确认、异常处理和失联安全停车机制，用于提高无线控制场景下的可靠性。

## 说明与限制

- 密码核心基于公开参考实现，项目重点在接口适配、系统集成、事务控制、故障定位和验证，而非从零设计密码算法核心；
- 仓库经过脱敏处理，不包含真实密钥、Wi-Fi凭据、完整固件和未处理原始日志；
- 超声波实体未完成安装，仅完成相关接口设计和软件/RTL验证，不声明真实距离测量结果。
