# Secure Wireless Control System on FPGA and Embedded Platforms

## 项目概览

本项目实现了一个基于 PC、ESP32、FPGA 和 STM32 的端到端安全无线控制系统，以四轮小车作为真实执行载体，完成无线通信、FPGA侧数据处理、嵌入式控制和设备状态回传。

作品参加第十届全国大学生集成电路创新创业大赛 Robei 企业命题，获华中分赛区二等奖。

## 系统架构

```
PC控制端
    ↓ Wi-Fi / UDP
ESP32通信模块
    ↓ UART
FPGA处理模块
    ↓ UART
STM32控制模块
    ↓
电机执行设备
```

系统将网络接入、安全事务处理和物理执行进行分层设计，实现从控制请求发送、设备侧处理到状态反馈的闭环流程。

详细架构说明见：

- [Architecture Source](architecture.mmd)

## 硬件平台

系统由以下硬件组成：

- Artix-7 FPGA开发板（XC7A50T）；
- ESP32 Wi-Fi通信模块；
- STM32嵌入式控制板；
- 四轮移动执行平台。

硬件照片和平台说明见：

- [Hardware Description](docs/hardware.md)

## 系统组成

### PC控制端

- 生成控制请求；
- 进行通信交互和状态显示；
- 接收设备返回状态。

### ESP32通信模块

- 提供 Wi-Fi 网络接入；
- 完成 UDP 数据收发；
- 实现网络与串口之间的数据桥接。

### FPGA处理模块

- 完成通信协议处理；
- 进行安全事务控制和状态校验；
- 集成密码处理接口与车控事务逻辑。

### STM32控制模块

- 解析控制指令；
- 完成 PWM/GPIO 电机控制；
- 生成设备状态；
- 实现异常情况下的安全停车。

## 主要工程工作

- 完成系统总体架构设计、模块划分和设备接口定义；
- 完成 PC、ESP32、FPGA、STM32 四节点通信链路集成；
- 完成 ESP32 Wi-Fi/UDP 通信与 UART 桥接调试；
- 完成 STM32 控制逻辑、电机驱动、状态回传和失联停车机制；
- 基于公开 AES/SM4 参考核心完成 FPGA 接口适配、事务控制和系统集成；
- 完成软件、RTL、综合实现和真实硬件环境下的分层测试与问题定位；
- 建立代码版本、固件产物、bitstream 和测试日志的可追溯记录。

## 工程特点

### 多节点软硬件协同

项目涉及网络通信、FPGA逻辑、嵌入式控制和真实执行设备，需要完成多个软硬件模块之间的接口设计与联合调试。

### 分层验证流程

针对复杂系统调试，采用模块验证、链路验证和整机测试相结合的方法，分别验证通信、协议处理、控制执行和异常保护功能。

### 安全与可靠性设计

系统包含通信校验、状态确认、异常处理和失联安全停车机制，提高无线控制场景下的可靠性。

## 项目开发流程

项目按照以下流程推进：

1. 系统需求分析与模块划分；
2. PC、ESP32、FPGA、STM32接口设计；
3. 分模块开发与验证；
4. 软件、RTL和综合结果联合测试；
5. 实物环境调试；
6. 端到端链路验证。

## 项目边界说明

- 密码核心基于公开参考实现，项目重点在接口适配、事务控制、系统集成、故障定位和验证，而非从零设计密码算法核心；
- 仓库经过脱敏处理，不包含真实密钥、Wi-Fi凭据、完整固件和未处理原始日志；
- 超声波实体未完成安装，仅完成相关接口设计和软件/RTL验证，不声明真实距离测量结果。
